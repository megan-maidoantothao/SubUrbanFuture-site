# Suburban Futures

Suburban Futures is a data story about population growth and social
infrastructure across Greater Melbourne. It asks whether the services that
support communities, such as health, education and community facilities, are
keeping pace with growth, first across the city and then within individual
councils.

**View the site:** <https://megan-maidoantothao.github.io/SubUrbanFuture-site/>

## Stories

- **Melbourne**: how population growth and mapped facilities changed across
  354 SA2 areas between 2021 and 2024, with an animated view of council
  population from 2010 to 2024.
- **Wyndham**: how growth and facilities differ between established areas and
  growth corridors within one council, with an interactive SA2 chart.
- **Cardinia, Casey, Hume, Melton, Mitchell and Whittlesea**: which types of
  services are falling behind fastest in each growth-area council.

## Built with

R for data preparation and static charts, Quarto for the website, and D3.js
for the interactive charts. The site is hosted on GitHub Pages.

## About this repository

This repository contains the generated website only: HTML pages, chart data
and images. The source code and analysis are maintained in a separate
repository, and this one is updated automatically each time the site is
published.

## Data

The underlying data belongs to the University of Melbourne and is not
included here. The site presents aggregated summaries by SA2 area and council,
prepared for the published charts.
